# Novel Workbench

โต๊ะทำงานสำหรับนักเขียนนิยาย รวมต้นฉบับ ตัวละคร ฉาก เกร็ดโลก และโครงเรื่องไว้ในที่เดียว เขียนไปดูข้อมูลไป ไม่ต้องสลับไฟล์หรือเปิดหลายหน้าต่าง

แอปออกแบบมาเพื่อเรื่องยาวที่มีรายละเอียดเยอะ ทำงานบน Windows ใช้ได้ทั้งภาษาไทยและอังกฤษ มีธีมสว่างและมืด และเก็บงานเขียนทั้งหมดไว้ในเครื่องของคุณ

## ทำอะไรได้บ้าง

### เขียนได้ต่อเนื่อง

- หน้าเขียนโล่ง ปรับฟอนต์ ขนาด ระยะบรรทัด และความกว้างหน้าได้ตามที่อ่านสบาย
- โหมดโฟกัสซ่อนทุกอย่าง เหลือแค่งานเขียนเต็มจอ
- บันทึกให้อัตโนมัติ ไม่ต้องคอยกดบันทึก
- ติดสถานะแต่ละบทเป็นร่าง กำลังแก้ หรือเสร็จ และเปลี่ยนทีละหลายบทได้
- จดสรุปและโน้ตส่วนตัวของแต่ละบท โดยไม่ปนกับเนื้อเรื่อง

### จำรายละเอียดของเรื่องแทนคุณ

- เก็บตัวละครและสถานที่เป็นการ์ด ใส่แท็ก เลือกสี และเพิ่มหัวข้อเองได้ ตัวละครใส่รูปได้ด้วย
- คลังคำศัพท์แยกระบบพลัง เกร็ดโลก และศัพท์เฉพาะ จัดเป็นโฟลเดอร์ได้
- ระหว่างเขียน แอปเสนอชื่อที่บันทึกไว้ให้เติมได้ทันที ช่วยให้สะกดตรงกันทั้งเรื่อง
- ชื่อในเนื้อหามีเส้นประ ชี้เมาส์เพื่อดูข้อมูลได้เลย และเปิดแผงอ้างอิงค้นต่อได้โดยไม่ต้องออกจากหน้าเขียน

### วางโครงเรื่องเห็นภาพ

- กระดานอิสระสำหรับระดมความคิด
- ผังความสัมพันธ์ของตัวละคร
- เส้นเวลาของฉาก พร้อมสร้างบทจากฉากบนกระดานได้

### แก้ต้นฉบับยาว ๆ ได้สบาย

- ค้นหาและแทนที่ทั้งบทหรือทั้งเรื่อง รองรับ Regex สำหรับงานแก้ที่ซ้ำซาก
- นำต้นฉบับเดิมเข้ามาเป็นบทจากไฟล์ Word, ข้อความ หรือ Markdown

### ส่งงานต่อได้ทันที

ส่งออกเป็น Word, PDF, EPUB, Markdown หรือข้อความธรรมดา เลือกส่งทั้งเรื่องหรือเฉพาะบางบทก็ได้

## งานเขียนของคุณปลอดภัย

- เก็บข้อมูลในเครื่องของคุณ ไม่ต้องฝากต้นฉบับไว้บนคลาวด์
- สำรองข้อมูลให้อัตโนมัติ
- ลบพลาดก็กู้คืนจากถังขยะได้ภายใน 30 วัน

## สิ่งที่ต้องมี

- Windows
- คีย์สำหรับเปิดใช้งาน
- อินเทอร์เน็ตตอนเปิดใช้งานครั้งแรก และอย่างน้อยทุก 30 วันเพื่อตรวจสอบสิทธิ์ นอกจากนั้นเขียนแบบออฟไลน์ได้
